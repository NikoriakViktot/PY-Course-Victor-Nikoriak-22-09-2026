# Legacy: Meteo Telegram API (v1)

Оригінальний код викладача — для розбору «як було» в уроці 33. **Не запускається в уроці** (потрібні MongoDB і доступ до ogimet.com).

- `main.py` — FastAPI + MongoDB, з проєкту `ogimet-main/meteo_telegram/main.py`
  (перша версія — репозиторій [`NikoriakViktot/ogimet`](https://github.com/NikoriakViktot/ogimet), 2024).
- `streamlit_app.py` — Streamlit-клієнт до цього API з того самого проєкту.

REST-версія того самого API — `../app.py` (урок 33).
