# Self-paced. AI для розробників (бонус)

🚧 Контент у розробці. Самостійний трек «поза сіткою» (~14 год.), не входить до основних 6 модулів.

Правила використання AI діють у **всіх** модулях курсу, не лише в цьому треку:

- [Урок 1](m1/lesson_01.md) — AI-політика курсу: два режими роботи (самостійно й з AI), цикл `ASK → PREDICT → RUN → VERIFY → EXPLAIN → ADAPT`, позначка `# AI log: ...` у домашній роботі;
- [Урок 26](m2/lesson_26.md) — тести як перевірка коду, написаного AI;
- [Урок 43](m4/lesson_43.md) — AI-інструменти розробника, ризики й рецензія AI-коду тестами; довідник [Claude Code](m4/ai/claude_code.md).
