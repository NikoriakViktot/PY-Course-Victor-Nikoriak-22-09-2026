# Урок 1. Вступний урок: формат курсу, AI-політика

Організаційний урок — не задача→рішення, а знайомство з правилами роботи.

Що на ньому відбувається:

- карта заняття (learning outcomes) і модель курсу — книга vs ноутбуки занять;
- як влаштований Jupyter Notebook (markdown vs code cell, Shift+Enter) — мінімум, потрібний для першої вправи;
- вправа «Крок 0 — представтесь» — перший реальний запуск code cell, з повторним запуском після зміни значень;
- AI-політика курсу в студентському форматі: два режими роботи — **самостійна перевірка** (без AI) і **робота з AI** (цикл `ASK → PREDICT → RUN → VERIFY → EXPLAIN → ADAPT`, з обов'язковою перевіркою й позначкою `# AI log: ...` у домашній роботі), таблиця корисного/некорисного використання і міні-сценарії на класифікацію режиму;
- короткий вступ до Git/GitHub-треку — розмежування Git (система історії) і GitHub (сервіс), workflow до Pull Request — точка входу в Git-трек, що триватиме весь модуль;
- самоперевірка на розуміння уроку (без AI) і чекліст готовності до Уроку 2.
