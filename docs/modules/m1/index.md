# М1. Основи Python

<p class="m1-subtitle">Від першої програми до власного консольного застосунку</p>

Програма починається із задачі: порахувати виторг ресторану, обробити замовлення або реалізувати правила гри. У цьому модулі ти навчишся представляти такі задачі даними, описувати їхню обробку мовою Python та поступово збирати окремі рішення в завершену програму.

Працюватимемо з різними прикладами — від звіту кафе за днями до пошуку й хеш-таблиць. Наприкінці модуля ти поєднаєш вивчене у власному консольному застосунку.

## Чого ти навчишся

- представляти інформацію числами, рядками та колекціями — списками, кортежами, множинами й словниками;
- описувати правила й повторювані дії через умови та цикли;
- організовувати код у функції та модулі;
- обирати спосіб пошуку й оцінювати, скільки роботи виконує твій код;
- обробляти помилки, читати й зберігати дані у файлах;
- зберігати історію змін і здавати роботу через GitHub.

## Як проходити модуль

1. Прочитай пояснення й розбери приклади на сторінці уроку.
2. Відкрий ноутбук заняття (посилання й кнопка Colab — на сторінці уроку), передбач результат і лише потім запусти код.
3. Зміни приклад і виконай самостійні завдання.
4. Здай домашню роботу за інструкцією [«Здача домашніх робіт»](../../00_getting_started/homework_workflow.md).

GitHub використовуємо з початку навчання для здачі робіт; на окремому занятті докладніше розберемо історію змін, гілки й Pull Request.
