# Смачно + Таксі — фінальний проєкт модуля 1

Весна 2020-го, карантин і бум доставки: зали кафе зачинені, пасажирів у таксі немає, тож кафе «Смачно» готує, а водії таксі розвозять. Консольна система обліку доставки для обох. Стан зберігається в `data.json` і переживає перезапуск програми.

```bash
python app.py import kasa_2024_07.txt              # замовлення з файлу каси
python app.py add-order "2024-07-22 12:40;310.00;20;1"
python app.py add-delivery 1 Оболонь 230 D-3        # доставка замовлення №1
python app.py find 1
python app.py report
python app.py voucher 500
```

Потрібен лише Python 3.10+ і стандартна бібліотека.

## Шість частин

| № | Файл | Що зробити | Урок |
|---|---|---|---|
| 1 | `rules.py` | `meal_type`, `day_name` | 12 |
| 2 | `parsing.py` | `parse_order`, `parse_delivery` | 13 |
| 3 | `storage.py` | `save_state`, `load_state` | 14 |
| 4 | `cafe.py` | `cafe_stats` | 6, 7, 12 |
| 5 | `taxi.py` | `delivery_index`, `top_districts`, `voucher_pair` | 11, 16 |
| 6 | `commands.py` | `next_id`, `add_order`, `import_kasa`, `add_delivery`, `find_order`, `report`, `voucher` | 7, 13 |

`models.py`, `app.py`, `check.py` і `tests/` дає викладач. Контракт кожної функції — у її докстрінгу.

Роби частини **по порядку**: частина 4 використовує частину 1, частина 6 — частини 1, 2, 4 і 5. Якщо тест пише «ще не зроблено — частина 2: …», спершу допиши частину 2.

```bash
python check.py        # таблиця: яка частина готова
python check.py 3      # тести частини 3
python check.py all    # усі частини + сесія адміністратора через app.py
```
