## Що показати на занятті

1. Обрати задачу диспетчера й відкрити код обох рішень.
2. Попросити групу **передбачити**, у скільки разів зросте кількість кроків, коли поїздок удвічі більше. Кнопка запуску недоступна, поки не обрано обидва прогнози.
3. Запустити дослід: n/8, n/4, n/2, n — щоразу вдвічі більше.
   - обидва рішення дають однакову відповідь — правильні обидва;
   - повільне: кроки зростають ×4 (`O(n²)`), швидке — ×2 (`O(n)`);
   - мілісекунди від запуску до запуску трохи різні, кроки — ні.
4. «Місто росте»: оцінка часу для 10 000 — 10 000 000 поїздок. Години чи дні проти мілісекунд.

## Чотири задачі

| Задача | Повільне | Швидке |
|---|---|---|
| Повторний номер поїздки | усі пари: `O(n²)` | множина побачених: `O(n)` |
| Водії двох змін | `in` для списку в циклі: `O(n·m)` | множина вівторка: `O(n + m)` |
| Клієнти для розсилки без повторів | `not in` для списку, що росте: `O(n²)` | допоміжна множина: `O(n)` |
| Найшвидше повернення клієнта | усі пари: `O(n²)` | словник «остання поїздка»: `O(n)` |

## Файли

- `taxi_core.py` — дані, вісім рішень з лічильниками кроків, таблиця подвоєння. Чистий Python.
- `app.py` — інтерфейс Streamlit, лише викликає `taxi_core.py`.
- `test_taxi_core.py` — перевірки: `python test_taxi_core.py`.

Кроки рахуються так: одне порівняння двох значень або одна перевірка / запис у множині чи словнику — один крок. Цикл, який у повільних рішеннях замінює `in` для списку, показує роботу, що зазвичай прихована всередині `in`.
