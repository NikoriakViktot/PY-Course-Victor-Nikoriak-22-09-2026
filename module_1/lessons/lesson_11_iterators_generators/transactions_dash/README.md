# Біржовий потік — Dash-застосунок до уроку 11

Демонстрація до [уроку 11 «Ітератори й генератори»](../../../../docs/modules/m1/lesson_11.md): нескінченний генератор біржових угод на графіках у реальному часі. Нафтогаз, ПриватБанк, Розетка, Укрнафта, Київстар — ціни, обсяги, ковзне середнє, стрічка останніх угод.

## Запуск

```bash
pip install dash plotly
cd module_1/lessons/lesson_11_iterators_generators/transactions_dash
python app.py
```

Відкрий `http://127.0.0.1:8059`. Інтернет і файли даних не потрібні.

**Джерело «Файл NDJSON з ноутбука»** стає доступним, якщо запустити ноутбук [`lesson_11_transactions_streaming.ipynb`](../lesson_11_transactions_streaming.ipynb) локально з теки уроку. Він створить `data/transactions.ndjson`, а застосунок програватиме угоди з цього файлу потоково, по колу.

## Що показати на занятті

1. Панель «Як це працює»: угоди дає `transaction_stream()` — `while True` + `yield`. Кожен тік бере з генератора N угод через `next()`.
2. Лічильник «усього оброблено» росте, а в пам'яті лише останні точки вікна (`deque(maxlen)`) — повзунок «Розмір вікна».
3. Зняти й поставити компанію: генератор не перезапускається, ціни не скидаються — вибір лише фільтрує відображення.
4. Перемкнути джерело на файл: той самий інтерфейс, інше джерело-генератор.

## Чим цей код відрізняється від прототипу

Прототип `app_transactions_dash.py` мав проблеми з генерацією:

| Проблема прототипу | Що відбувалося | Як зроблено тут |
|---|---|---|
| один генератор у глобальній змінній, `next()` з кількох потоків | Dash виконує callback-и паралельно → `ValueError: generator already executing`. На навантажувальному тесті падали 1500 з 1800 викликів | `next()` лише в `MarketState.advance()` під `threading.Lock` |
| графіки читали `deque`, поки в них писали | непослідовні графіки, ризик `RuntimeError` | усі графіки малюються з одного знімка `snapshot()` |
| файл читався в пам'ять цілком і перемішувався | суперечило ідеї уроку; без `data/transactions.ndjson` застосунок падав з `FileNotFoundError` | за замовчуванням — нескінченний генератор; файл читається потоково (`read_ndjson`), компанії зливаються за часом через `heapq.merge` |
| вісь X — рядки `HH:MM:SS` з різних днів упереміш | лінія «стрибала», однакові мітки зливались | час угод лише зростає, на осі — `datetime` |
| жодної вибраної компанії у файлі | генератор крутився вічно, callback зависав | потік завершується, статус «Потік завершився» |
| зміна компаній чи вікна | генератор перезапускався, ціни й зміни скидались | генератор один на всі компанії; вікно змінюється зі збереженням останніх точок |

Тест `test_shared_generator_without_lock_breaks` відтворює стару помилку, а `test_state_is_thread_safe` перевіряє, що з `MarketState` її немає: 8 потоків × 200 кроків, усі угоди пораховано.
